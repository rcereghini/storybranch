# Web documentation routing

Before planning or changing Story-related files here or in child folders, read [STORY_COMPONENTS.md](STORY_COMPONENTS.md) and its relevant canonical links. This includes player renderers, Studio, graph/outline/library, context adapters, media, CSS and tests of these flows. Read [the design system](../../../docs/21-design-system.md) for UI changes.

The root instructions still apply. A new child folder inherits this reading requirement; add a local guide when it introduces a distinct responsibility. Keep this file a routing guide rather than a duplicate architecture specification.
